# Server Helper (Fabric 1.16.5)

Меню на **Insert**. Там назначаешь бинды:
- Трапка
- Пласт
- Зелье киллера
- Зелье медика

Нажми на кнопку, потом нужную клавишу (или кнопку мыши 3+). **Esc** убирает бинд.
Бинды работают, когда меню закрыто. Настройки сохраняются в `config/serverhelper.json`.

Предметы ищутся по названию (хотбар, потом инвентарь): «трапк», «пласт», «киллер», «медик».
Для зелий предмет должен быть зельем. Если предмет в инвентаре, он на миг меняется местами с рукой.
Для зелий есть опция «кидать под ноги» (по умолчанию: медик — да, киллер — нет).

## Сборка jar (нужна Java 8+ и интернет; Gradle ставить не надо)

В папке проекта:
```
gradlew.bat build      # Windows
./gradlew build        # Linux/Mac
```
Готовый файл: `build/libs/serverhelper-1.0.0.jar` (не `-sources`). Кладёшь в `mods/` вместе с Fabric Loader и Fabric API 0.42.0+1.16.
